### Recommendation for a Small Mobile App's Local Storage

**Recommendation: SQLite**

#### Justification:

For the specific use case of **local storage on a mobile device**, SQLite is the industry standard for the following reasons:

1.  **Zero Operational Overhead:** Unlike PostgreSQL or MongoDB, SQLite does not require a client-server architecture. There is no "server" to start or manage on the user's phone; the database is simply a file residing in the app's sandbox.
2.  **Zero Latency:** Because the database engine runs within the same process as the mobile application, there is no network overhead or inter-process communication latency. This makes data retrieval near-instantaneous.
